Tentang model

Model berasal dari penelitian skripsi Klasifikasi Penyakit Daun Padi Menggunakan ResNet-50 Transfer Learning dan Interpretasi Grad-CAM.

Performa

97,33%Akurasi data uji (75 citra)
96,36%Macro F1 data uji
98,40%Akurasi 5-fold (± 0,89)
98,07%Macro F1 5-fold (± 1,15)

Arsitektur

  1. Input 224×224×3 + preprocess_input
  2. ResNet-50 (bobot ImageNet)
  3. Global Average Pooling
  4. Dropout 0,3 → Dense 256 ReLU → Dropout 0,3
  5. Dense 3 Softmax

Pelatihan dua tahap: kepala klasifikasi dengan Adam (lr 0,001), lalu fine-tuning 30 layer teratas dengan Adam (lr 0,00001). Augmentasi berupa flip horizontal, rotasi, zoom, dan kontras. Bobot kelas dipakai untuk menyeimbangkan kelas tungro.

500 citra daun padi (Kaggle), dibagi 70:15:15 secara stratified.

Grad-CAM

Grad-CAM dihitung pada layer conv5_block3_out. Gradien skor kelas terhadap feature map dirata-ratakan menjadi bobot tiap kanal, lalu kombinasi berbobotnya dilewatkan ReLU dan dinormalisasi. Warna merah menandai area yang paling memengaruhi keputusan model.

Batasan

  • Model hanya mengenal 3 kelas. Belum ada kelas daun sehat, sehingga foto daun sehat tetap akan diberi label penyakit.
  • Analisis Grad-CAM menunjukkan sekitar 66% intensitas heatmap jatuh di latar belakang, jadi foto dengan latar polos memberi hasil lebih andal.
  • Dataset kecil (500 citra) dan kelas tungro paling sedikit (80 citra), sehingga akurasi di lapangan bisa lebih rendah.
  • Versi web memakai bobot float32 penuh (TensorFlow.js), sehingga hasilnya sama dengan model di notebook. Pemuatan pertama mengunduh ±96 MB.
