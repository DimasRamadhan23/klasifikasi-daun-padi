Tentang model

Arsitektur

  1. Input 224×224×3 + preprocess_input
  2. ResNet-50 (bobot ImageNet)
  3. Global Average Pooling
  4. Dropout 0,3 → Dense 256 ReLU → Dropout 0,3
  5. Dense 3 Softmax

Dilatih 2 tahap: kepala klasifikasi (Adam 1e-3), lalu fine-tuning 30 layer teratas (Adam 1e-5). Grad-CAM dihitung pada layer conv5_block3_out.

Dataset

500 citra daun padi (Kaggle), dibagi 70:15:15 secara stratified.
